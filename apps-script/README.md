# Apps Script glue

1. Sign in as `sundaypowerprojectspvt@gmail.com`.
2. Open the **Sunday Solar Expenses** Sheet → **Extensions → Apps Script**.
3. Paste [`Code.gs`](./Code.gs) and save.
4. Set Script Properties: `EXPENSE_PASS`, `SHEET_ID`, `FOLDER_ID`.
5. Deploy as Web app: **Execute as Me**, **Anyone**.
6. Put the `/exec` URL into `../src/config.js` → `APPS_SCRIPT_URL`.

Full steps: [../README.md](../README.md).
